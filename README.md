# Task Manager API

A RESTful Task Manager API built using FastAPI, SQLAlchemy, and JWT Authentication.

## Features

* User Registration
* User Login Authentication
* JWT Token Authentication
* Create Tasks
* Get Tasks
* Update Tasks
* Delete Tasks
* Protected Routes

## Technologies Used

* Python
* FastAPI
* SQLAlchemy
* SQLite
* JWT Authentication
* Uvicorn

## Installation

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
